# 🚀 Space Shooter Game

## 📌 About the Project

**Space Shooter Game** is an arcade-style game in which players control a spaceship to shoot enemies, avoid obstacles, and survive in space. The game focuses on improving player reflexes, coordination, and strategic thinking while providing an entertaining gaming experience.

## ✨ Features

- 🚀 **Spaceship Control:** Move the spaceship to navigate through space.
- 🔫 **Shooting Mechanism:** Fire bullets to destroy enemy spaceships.
- 👾 **Enemy System:** Face enemies and avoid incoming attacks.
- 💥 **Collision Detection:** Detect collisions between bullets, enemies, and the player.
- 🏆 **Scoring System:** Earn points by defeating enemies, if implemented.
- 🎮 **Interactive Gameplay:** Enjoy a simple and engaging arcade experience.

## 🎮 How to Play

1. Start the game.
2. Control your spaceship using the available keyboard controls.
3. Shoot enemy spaceships to destroy them.
4. Avoid enemy attacks and collisions.
5. Try to achieve the highest score possible.
